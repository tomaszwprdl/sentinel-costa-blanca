LOGO-GEOMETRY-SPEC.md

Status: Geometry Locked — Production Reference

This document defines measurable construction logic for the Sentinel mark.
It replaces ambiguity with proportional clarity.

This is not a concept file.
This is an execution specification.

1. Foundational Grid System

The mark is constructed on a square 1:1 canvas.

Base construction grid:

Divide the square into 12 equal units per side.

This creates a 12×12 structural grid.

All geometry derives from this system.

No arbitrary placement.

2. Outer Frame Construction

Outer boundary = full 12×12 square.

Frame thickness = 1 grid unit.

This establishes:

Outer boundary weight = 1
Internal offset zone = 1 unit minimum

The frame must read clearly at small scale without appearing dominant.

3. Inner Containment Offset

Inner structural field begins at:

1.5 grid units inward from outer boundary.

This creates:

1 unit visible frame
0.5 unit breathing buffer
Then internal structure

This prevents compression while preserving containment clarity.

Internal geometry must not touch the outer frame.

Ever.

4. Structural Hierarchy Order

Visual reading order must remain:

1️⃣ Outer structural mass
2️⃣ Inner containment geometry
3️⃣ Micro internal logic

If internal geometry competes with frame dominance → reject.

Frame remains jurisdiction.

Interior remains operational.

5. Symmetry Discipline

Macro symmetry is mandatory.

Left and right halves must mirror structurally.

Micro optical corrections are allowed:

≤ 3% proportional adjustment
Only for visual balance
Never for expressive asymmetry

No visible directional push.

6. Corner Engineering

Outer frame corners:

Hard 90° geometry
Micro-radius allowed: ≤ 2% of total width

Radius must be imperceptible, purely optical.

Inner geometry corners must follow same logic.

No expressive rounding.

7. Negative Space Rules

Negative space must:

• Reinforce structural logic
• Maintain stability
• Avoid decorative voids
• Avoid symbolic reading

No cutouts thinner than 1 grid unit.

Minimum internal stroke/void thickness = 1 unit.

This ensures 16px survival.

8. Weight Calibration

Visual center must be optically neutral.

No top heaviness.

If any weight bias exists, it may lean ≤ 2% downward optically.

But must not be visibly bottom-heavy.



9. Scale Testing Protocol (Mandatory)

Before any iteration is considered viable, it must pass:

• 16px test (favicon scale)
• 32px test
• Black-only test
• White-on-black inversion test
• 300dpi grayscale print test
• Blur test (Gaussian blur 3px equivalent)

If silhouette collapses → reject.

If frame disappears → reject.

If internal logic vanishes → simplify.

10. Prohibited Structural Behaviors

• No touching outer frame
• No frame breaks
• No open corners
• No thin line symbolism
• No literal object outlines
• No internal geometry exceeding 50% visual mass
• No modular segmented appearance

The mark must feel:

Unified.
Contained.
Built.

11. Illustrator Setup Recommendation

Artboard: 1200×1200px
Grid: 12 divisions per side
Snap-to-grid: On
Outline mode frequently
Work in black only (#000000)

No color exploration at this stage.

## 12. Website scope note

Geometry, colors, and containment rules in this spec apply to **logo assets only**.

Page-level palette, imagery, and surface treatment are governed separately (`VISUAL-FREEDOM-SPRINT.md`, `DECISIONS.md` §12–13) and must not alter the mark.
