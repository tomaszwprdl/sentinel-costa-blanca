## Purpose

This document protects the conceptual integrity of the Sentinel mark.

It does not define geometry.  
It does not define drafting measurements.  
It defines meaning boundaries and recognition integrity.

Geometry authority belongs to:
LOGO-GEOMETRY-SPEC.md

Psychological doctrine belongs to:
BRAND.md

This document ensures the mark is never reinterpreted.

---

# 1. Core Concept (Locked)

The Sentinel mark represents:

Monolithic institutional containment  
expressed through architectural abstraction.

It communicates:

- Defined perimeter
- Internal order
- Structural governance
- Calm authority

It does not communicate function.
It communicates structure.

---

# 2. Concept Territory Boundaries

The mark must never drift toward:

- Security branding
- Surveillance symbolism
- Concierge aesthetics
- Property agency motifs
- Cleaning service identity
- Lifestyle positioning
- Startup visual energy

If reinterpretation pushes toward any of the above:
→ reject.

The mark represents governance, not service theatrics.

---

# 3. Recognition Hierarchy

The mark must read in this order:

1. Structural mass  
2. Contained geometry  
3. Internal logic  

It must not read as:

- Literal object
- Decorative symbol
- Functional metaphor
- Process diagram

If symbolic reading precedes structural reading:
→ concept integrity compromised.

---

# 4. Authority Tests (Ongoing Validation)

The mark must continuously pass:

## 4.1 3-Second Authority Test
Does it feel like a disciplined local institution?

## 4.2 16px Silhouette Test
Does the silhouette remain recognisable?

## 4.3 Black-Only Test
Does it function without color?

## 4.4 Inversion Test
Does it survive dark/light reversal?

## 4.5 Document Header Test
Does it feel credible on official PDF documentation?

Failure of any test requires review.

---

# 5. Prohibited Structural Behaviors

Future modifications must not introduce:

- Frame breaks
- Segmentation
- Open perimeters
- Floating elements
- Expressive asymmetry
- Decorative cutouts
- Symbolic additions
- Motion cues
- Visual aggression

The mark must remain:

Unified.  
Closed.  
Balanced.  
Institutionally grounded.

---

# 6. Color Dependency Rule

The mark must never rely on color for strength.

Color enhances structure.
It must not compensate for weak form.

If form weakens without color:
→ redesign required.

---

# 7. Reduction Model Integrity

The logo supports controlled reduction:

Full:
Symbol + Wordmark + Descriptor

Reduced:
Symbol + Wordmark

Minimal:
Symbol only

Descriptor must never appear without core name.

Hierarchy must remain intact across all formats.

---

# 8. Long-Term Protection Rule

The mark must answer this question indefinitely:

Must remain consistent with the Structural Identity Principles defined in BRAND.md.

If decorative → reject.
If structural → preserve.
