# CLN-02 — Checklista sprzątania i gotowości

Dokument roboczy wewnętrzny. Nie jest umową ani dokumentem do podpisu. Używany do jednej usługi sprzątania / gotowości. Zakres musi wynikać z SCO-01 lub późniejszego pisemnego potwierdzenia.

Ta checklista wykonuje jedno zdarzenie sprzątania / gotowości. Model sprzątania, granice i osobę wykonującą ustala SCO-01; checklista ich nie zmienia i nie otwiera na nowo.

## 11. Granice checklisty

- Ta checklista dokumentuje widoczną gotowość i wykonane czynności sprzątania.
- Nie jest certyfikatem higieny.
- Nie jest inspekcją techniczną ani diagnozą.
- Nie zastępuje SCO-01 i nie zmienia ustalonego zakresu.
- Nie tworzy nowego uprawnienia do wydatku.
- Przy osobie wybranej przez właściciela Sentinel dokumentuje wyłącznie widoczną gotowość i nie gwarantuje jej metody, terminu, produktów, obsady ani rezultatu.
